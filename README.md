# 作業登記系統 3.1 修正版

原生 HTML/CSS/JavaScript 前端，搭配 Google Apps Script 與教師限定的試算表。適用單一教師自主管理資料；共用 Token 並非多人帳號權限系統。

## 本版已實作

- 正式年度、班級、科目清單；可新增空班級與修改班級名稱。
- 四種繳交狀態、13 級等第、日期、全班批次操作與完整清除。
- 每次編輯先保留本機草稿；雲端成功需取得正確版本的 JSON 回覆，並由後端寫入後讀回核對。
- 完整名冊單元報表、按作業 ID 對齊的全班總覽、文字複製、圖片下載、列印／另存 PDF。
- CSV 欄名對應、引號／BOM／CRLF、重複座號與欄位驗證；有歷史紀錄時阻止直接更換原座號的學生。
- 雲端寫入加鎖與版本檢查；異動前備份、失敗還原及中斷後停止服務待復原。
- 手機學生列分行、鍵盤分頁操作、本機鎖屏焦點限制、零分與未評分分開。

## 開始使用

1. 先依 [試算表結構](docs/GOOGLE_SHEET_SETUP.md) 與 [GAS 設定](docs/GAS_SETUP.md) 建立獨立測試資料來源。
2. 前端使用 HTTPS 靜態網站提供服務。前端不需打包；正式發布檔案為 `index.html`、`css/`、`js/`、`vendor/`、`docs/`。
3. 初次本機畫面鎖密碼為 `1234`。在設定填入 GAS `/exec` 網址與此次分頁 Token，連線後建立年度與班級。
4. 先用學生代稱完成 [驗收清單](docs/ACCEPTANCE.md)，再安排正式資料切換。

本機畫面鎖不是 Google 登入，也不會加密瀏覽器資料。Token 只存在本次分頁的 sessionStorage；草稿存在 localStorage，依本版命名空間與雲端網址分開。複製分頁可能複製 sessionStorage；共用電腦使用後仍應關閉所有相關分頁。程式不再使用 `.env`／`VITE_*` 設定，不能把 Token 放進公開前端。

## 草稿與衝突

每次點選狀態、等第或日期即保存本機草稿，按「送出儲存」才寫入雲端。離線只能編輯曾載入的作業，重新載入網站本身仍可能需要網路；本版尚非離線安裝 PWA。

另一裝置已更新作業或名冊時會拒收舊版本。另一分頁改了同一份本機草稿也會暫停覆寫；每個編輯工作階段另存自己的復原副本，避免兩個分頁幾乎同時保存時只剩一份。先匯出目前草稿，再重新載入核對；要採用雲端資料可明確選擇「放棄本機草稿」。本版沒有自動合併衝突或匯入草稿 JSON 的介面。「匯出所有本機草稿」會一起包含歷次工作階段的復原副本；容量不足時請先匯出再清理本版本本機資料。

保存結果逾時時，請先重新載入：若雲端與草稿相同，系統會認定該次送出已成功。API 沒有自動重試；同版本重送遇到變更會拒絕，避免意外覆蓋。作業日期保存在每筆紀錄中，空名冊不能保存日期；有學生後即可保存。

## 開發與測試

使用 Node.js 22 或以上：

```text
npm ci --ignore-scripts
npm run check
npm test
```

測試只使用假資料、記憶體試算表與 jsdom，不連接 Google。jsdom 驗證 DOM／互動流程，不能取代真實瀏覽器版面、CSP、CORS、Canvas、列印與行動裝置測試。

前端圖片工具固定為 html2canvas 1.4.1，隨網站放在 `vendor/`，保留 MIT 授權。若更新 npm 套件，也需同步更新該檔案與授權；本版不於課堂使用時下載 CDN 腳本。

## 與 3.0／2.7 的關係

前端和 GAS 必須一起使用 3.1。既有 3.0 三表可先複製後手動初始化；原年度空學生列與空單元占位列會轉為正式清單，重複／孤兒／錯誤資料會停止遷移。不要把 3.1 前端直接指向 3.0 API。

2.7 的 API、名冊結構與作業狀態都不同，本版未提供自動 V2 遷移器。須先備份並指定學年度與 ID 對照；已繳狀態不能猜成 100 分。

## 尚待驗收與界線

2026-09-14 使用者已在獨立測試環境核對 GAS 儲存成功回應、試算表資料、單元報表、清除、基本匯出、桌面及 320／360／390px 模擬畫面。期間仍反覆出現連線逾時或回覆無法確認，尚未解決其根因；一次成功不能代表連線穩定性已通過。真實手機、其他瀏覽器、正式 HTTPS 來源及備份還原仍待驗收，詳見 [驗收紀錄](docs/ACCEPTANCE.md)。

正式教師登入、多使用者權限、穩定跨班 student_id、PWA、整批 V2 遷移均屬後續擴充。本版以保守名冊限制降低現有座號關聯風險。資安檢查與使用限制請見 [安全與資料保護](SECURITY.md)。

原始碼、瀏覽器草稿、Google 試算表是三份不同資料；Git／Google Drive 同步不能替代可還原的資料備份。
