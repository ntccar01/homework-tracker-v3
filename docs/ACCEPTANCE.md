# 3.1 驗收與發布紀錄

## 已可在本機自動驗證

執行 `npm run check` 與 `npm test`。測試為假資料，含前後端互動、GAS記憶體模型、資料規則與網路回應模擬。每次實際發布前重新執行，保留測試輸出。

- 空年度／空班級可保存；重複年度、錯誤Token、錯schema、重複座號會拒絕。
- 已繳、補交、缺交、免交、取消、全清、0分、空分數與完整名冊讀回一致。
- 舊revision拒絕；寫入成功但回覆遺失，可透過重新載入核對。
- 名冊失敗不破壞原資料；有歷史紀錄不能靜默改派座號。
- 日期、班級關聯由後端驗證；總覽欄位按作業ID排列。
- 失敗寫入還原；還原失敗留下中斷標記；人工復原保留安全備份。
- CSV引號／BOM／換欄／重複資料、惡意HTML作為純文字顯示。
- 草稿重開、斷網、快取寫入失敗、過期請求及其他分頁草稿不被靜默覆蓋。
